# CAELENDAR（星历）

给日程很满的大学生做的**一体化桌面日历**。界面品牌名 **CAELENDAR**；可执行文件仍叫 `星历.exe`（保持旧快捷方式/开机自启路径不变）。单个 exe，原生 Windows 程序，不用装 Python、不开浏览器页面：
**常规使用约 30 MB 内存，隐藏到托盘后约 25 MB，空闲 CPU 0%**。

- **重启入口**：关于页「重启星历」/ 托盘右键 / `⋯` 菜单；**五视图**：年 / 月 / 周 / 日 / 全部日程；日程视图支持 **列表 / DDL 作业看板**；**学习统计**（周/月/年课程投入、DDL 完成率、最忙时段、考试密度）（年视图=全年热力图）、**日期跳转**（顶部日历按钮 / 点击标题 / Ctrl+G）
- **重复日程**：每天、每周、每月（第几个周几）、每年；改一次 / 改此后所有 / 改整个系列
- **标签 / 优先级 / 状态 / 提醒 / 地点 / 链接 / 备注 / 颜色**
- **导入导出 .ics**（课表、手机日历、Google 日历、Outlook；导入自动跳过完全重复，合并后逐门课配色）
- **智能整理**：导入时自动识别课程（打「课程」标签 + 自动配色），并把有规律的每周重复课合并成可整组编辑的重复日程
- **桌面挂件**（全屏游戏/全屏应用时自动隐藏，退出后自动恢复）：常驻屏幕一角、可拖动；4 种布局（卡片 / 细条 / 今日清单 / 极简时钟）、4 套皮肤、80%–160% 大小、30%–100% 透明度可调
- **日程提醒 + 喝水提醒**：弹窗（跟随挂件皮肤/大小/透明度）+ 声音 + 稍后提醒 + 一键完成
- **挂件上直接完成最近日程**：点「接下来」右侧的 ✓，重复课只完成这一次（Ctrl+Z 可撤销）
- **字体字号自定义**：界面字体、数字字体，8 个区域分别调字体与字号
- **关闭窗口 = 隐藏到托盘后台运行**，提醒不断；支持**开机自启动**
- **批量添加**（重复规则 + 统一/自定义颜色，自动跳过完全重复）**/ 批量编辑 / 批量删除**（年/月/周/日/日程 五视图 Shift+点击多选、反选、Ctrl+A）、**批量调休 / 迁移课程**、**批量清理**、搜索筛选、撤销重做
- **年视图热力图**（12 个月全年分布、考试/截止/节日标记、点击跳转）、**农历 / 节日**（1901–2100 农历、闰月、春节/中秋等）、**8 套暗色主题（星轨/熔金/极光/绯夜/月白/樱夜/深海/森夜）**、18 色统一调色板 + 自定义颜色编辑器（HEX / RGB / CMYK）、学期周（单双周）

## 快速开始

1. 双击 **`星历.exe`**（或 `星历.lnk` 快捷方式）。**不会出现黑色命令行窗口**；首次运行会在同目录生成 `data\` 文件夹。
2. 建议右键 exe → 发送到 → 桌面快捷方式（或直接用附带的 `星历.lnk`）。
3. 双击月视图空白 = 新建；点日程 = 编辑；右键 = 更多操作。
4. 想改字体：设置 → 字体与后台 → 字体与字号…（当前默认：中文 Noto Sans SC，数字 Bahnschrift）。
5. 想开机自启：设置 → 字体与后台 → 勾选「开机自启动」，或右键托盘图标勾选。
6. 按 **F1** 看内置使用说明；完整文档见 [`docs/说明书.md`](docs/说明书.md)。

## 后台运行

- 点窗口右上角 ✕ 或最小化 = **隐藏到系统托盘**（右下角金色星星），提醒、挂件照常工作，内存自动降低约 5 MB。
- 托盘图标：左键打开主窗口；右键 → 退出星历 / 显示隐藏挂件 / 开机自启动等。
- 只有托盘右键「退出星历」或设置中关闭「隐藏到托盘」后关闭窗口，才会真正退出程序。

## 数据在哪

所有数据在程序目录的 `data\calendar.json`，每天自动备份到 `data\backup\`。
**换电脑时把整个文件夹拷走即可**。

## 说明

- 界面与文档均为中文；程序只在本机运行，不联网、不上传任何数据。
- 已知限制见验收报告（例如农历目前只显示公历节日）。
- 源码在 `src\`，可用 `build.bat` 重新编译（需要 MinGW-w64 g++ 15+）。
